## Quickstart

**Prerequisites:** Node `>=20`, Rust `>=1.80` (`cargo`), Python `>=3.11` + `uv`, Lean `4.35.0` (`elan`/`lake`), and Tectonic `0.17.0` (only for rebuilding PDFs).

```bash
git clone https://github.com/0thernes/human-synapse-bouton-lab.git
cd human-synapse-bouton-lab

# 1. Install pinned dependencies across all stacks
bash scripts/dev.sh setup

# 2. Build TypeScript core + WebGL app, Rust release engine, and Lean 4.35.0 proofs
bash scripts/dev.sh build

# 3. Run all unit, property-based (fast-check, proptest, hypothesis), API contract,
#    and 1,000-case cross-language differential tests (TypeScript vs Rust vs 50-digit Python)
bash scripts/dev.sh test

# 4. Launch the interactive 9-tab WebGL workbench locally
npm run dev
```

Expected test summary from a clean clone:
- Lean 4.35.0: `Build completed successfully (7 jobs)`, 18/18 axioms clean, `leanchecker-paranoid` exit 0
- TypeScript (`@synapse/core`): `12 passed (12)` (including 3,600+ `fast-check` property checks)
- Rust (`synapse-sim`): `5 passed` (including 2,000 `proptest` cases)
- Python (`synapse_science`): `9 passed` (including 1,000-case Python↔TS & 1,000-case Python↔Rust differential checks)

## Usage Examples

### 1. Run the FastAPI 50-Digit Exact Oracle Backend
```bash
uv run synapse-api
# Health check (expected: {"status":"ok","version":"1.0.0","oracle_precision_digits":"50"})
curl http://127.0.0.1:8000/healthz
```

### 2. Run the Standalone Cross-Language Examples (`examples/`)
```bash
node examples/nanocolumn_example.mjs
uv run python examples/exact_oracle_example.py
```

### 3. Run Pre-Registered Statistics, Honest Benchmarks & Media Generation
```bash
uv run synapse-stats                 # Regenerates data/experiments/* and data/MANIFEST.sha256
uv run synapse-media                 # Regenerates vector PDFs, PNGs, GIF, and H.264 MP4 videos
./target/release/synapse-sim bench   # Rust median: 0.3093 ms (IQR 0.0126 ms) for 5,000 APs x 10
npm run bench --workspace=@synapse/core  # Node median: 1.8362 ms (IQR 1.3254 ms)
```

### 4. Negative-Input Error Handling Example (Build Standard A04 / B06)
```bash
node -e "import('./packages/synapse-core/dist/index.js').then(m => m.analyzeExperimentalTrace('{bad'))"
# Throws: TraceParseError: Malformed JSON trace: Expected property name or '}' in JSON at position 1
```

## Limitations

See [`LIMITATIONS.md`](LIMITATIONS.md) for full details. Key boundaries:
- **Numerical Approximations:** Hodgkin–Huxley 4D RK4 trajectories and Monte Carlo sweeps use IEEE-754 float64 (`numerical_approximation`), not verified Lean interval ODE enclosures.
- **Visual Schematics:** Embedded 2D/3D visuals and animations are deterministic code-rendered educational models, **not** atomic-coordinate PDB/EMDB renders.
- **Consciousness Scope:** Lean bipartite-coupling theorems establish a necessary mathematical property of causal coupling; they do **not** prove, measure, or create phenomenal consciousness or sentience.
- **Review Status:** White papers are independent preprints and have not undergone external journal peer review.
