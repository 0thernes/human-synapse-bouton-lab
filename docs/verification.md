# Verification Architecture & Evidence Summary (`v1.4.0`)

`human-synapse-bouton-lab` implements all six layers of the Independent Scientist's Verification Stack (Defensible Research Playbook Edition 1.3):

1. **Multi-Kernel Lean 4.35.0 Formal Verification (`lean/`):**
   - **24 elementary lemmas** in isolated `Challenge.lean` / `Solution.lean` (`lake build --wfail`: 0 errors, 0 warnings, **0 unused hypotheses** across all 24 lemmas).
   - **27 concrete non-vacuity witness theorems** (`NonVacuity.lean`) and **7 sanity and sharpness checks** (`AdversarialChecks.lean`, `A01`–`A07`, including explicit negations and `A07` proving `T15` is an upper bound).
   - **Lean-to-Engine Vector Parity (`ExportVectors.lean`):** Directly evaluates `Solution.lean` definitions to emit `data/lean_engine_vectors.json`, diff-checked in CI and asserted in Python (`test_differential.py`), TypeScript (`synapse.test.ts`), and Rust (`lib.rs`). These are known elementary facts about the repository's own model formulas and resolve no published open question.
   - **Enforced Axiom Footprint (`docs/lean-axioms-report.txt`):** Drift-checked against `README.md` by `scripts/check_readme_axioms.py`. Strictly forbids `sorryAx`, `Classical.choice`, `Lean.ofReduceBool`, `Lean.trustCompiler`, and `_native` across `lean/comparator.json` (`permitted_axioms: ["propext", "Quot.sound"]`), CI grep, `scripts/dev.sh`, and `check_readme_axioms.py` (every lemma uses `[]`, `[propext]`, or `[propext, Quot.sound]`). `Challenge.lean` holds 24 `sorry` statement stubs used only by the comparator.
   - **Independent Multi-Kernel Replay:** Verified across `58,038` declarations locally by `lean`, `leanchecker`, `leanchecker-paranoid`, `nanoda_bin`, `con-ron`, and `con-leche` (standalone `nanoda_bin` receives `Classical.choice` solely in its JSON config so it can type-check transitive `Init` declarations without panicking; zero `Classical.choice` on all 24 exported theorems is enforced by `comparator.json` and `VerifyAxioms.lean`). In public Ubuntu CI, `lake check --paranoid` replays all default targets on 6 kernels (`lean`, `leanchecker-paranoid`, `lean4lean`, `nanoda`, `con-leche`, `con-ron`), and `lake comparator --paranoid` checks `Solution` against `Challenge`.
2. **Statement Fidelity Audit & Live Blueprint:** Complete line-by-line mapping in [`docs/statement-fidelity.md`](statement-fidelity.md), White Paper 1 Table 2, and interactive SVG dependency DAG at [`blueprint/index.html`](../blueprint/index.html) (live at `/blueprint/`).
3. **50-Digit Exact Oracle & 1,000-Case Differential Testing:** `python/synapse_science/oracle.py` (`mpmath` `dps=50` using exact `mp.log(10)` and $2\sqrt{2\ln 2}$, plus exact `Fraction` and `math.isfinite()` boundary guards) verified against TypeScript (`@synapse/core`) and Rust (`synapse-sim`) over 1,000 seeded random inputs (`0` mismatches within `1e-10`) plus Lean vector parity (`1e-12`).
4. **Property, Negative, Regression, Metamorphic & Control-Verified Mutation Verification:**
   - Property-based testing: `fast-check` (3,600+ cases), `proptest` (2,000 cases), `hypothesis` (1,500 cases).
   - Negative boundary guards: explicit `BiophysicsValidationError` (including `u0 <= 1`), `TraceParseError` (including monotonic timestamp enforcement), Rust `SimError` (including `firing_rate_hz >= 0`), Python `ValueError` (`NaN`/`Inf`), escaped WebGL fallback in `scene3d.ts`, and FastAPI HTTP 422.
   - Hardened mutation audit (`B13`, `F35`): `scripts/mutation_audit.py` first runs an **unmutated baseline control** (`rc = 0` + temp-dir import check), then plants 6 core biophysical mutants (`M01`–`M06`, including `M04` resting leak drop) in isolated temp copies and requires strict `rc = 1` test failures (**6/6 genuinely killed, 100.0%**).
5. **Pre-Registered Simulator Experiments:** `PREREGISTRATION.md` committed at root SHA `a1919f2` before any code (hypotheses, seeds, and statistics fixed; illustrative model constants set in code after registration); 30-seed Monte Carlo sweep (`1000..1029` + null `2000..2029`), Holm–Bonferroni correction, honest disclosure of pre-registered H3 (`40 Hz`) failure in the fixed-parameter simulator (`T15` upper bound $t \ge 3\,$s under mean rates), logged exploratory `H3b` (`20 Hz`) in `DEVIATIONS.md`, Croissant 1.0 metadata (`croissant.json`), and `data/MANIFEST.sha256`.
6. **Live Citation Integrity & Tamper-Evident Provenance:** `scripts/verify_citations.py` (brace-balanced BibTeX parser backed by negative unit tests in `python/tests/test_citations.py`) verifies **28/28 DOI-bearing entries** live against Crossref for HTTP 200, normalized title Jaccard, first-author surname, year, and `updated-by` Retraction Watch status (`0` mismatched, `0` retracted; 1 publisher correction notice on Wang 2024) plus 1 non-DOI entry (`chalmers1995facing`, total 29). Sealed by `MANIFEST.sha256`, DigiCert RFC 3161 `MANIFEST.sha256.tsr`, OpenTimestamps `MANIFEST.sha256.ots` (when anchored), `dist/SHA256SUMS`, `sbom.cdx.json`, `CITATION.cff`, `CITATION.bib`, `.zenodo.json`, GitHub SLSA release attestations (`actions/attest-build-provenance@v4`), Software Heritage SWHIDs, and `0thernes-research-archive` registration (`docs/PRESERVATION.md`).
