# Failure-Mode Analysis (`failure-modes.md`)

Prepared per Build Pipeline Models v1.0.0 (`P3.07`).

| Component | Failure Mode | Severity | Detection Mechanism | Mitigation & Recovery |
|---|---|---|---|---|
| **Lean 4.35.0 Formal Proofs (`lean/`)** | Accidental `sorry`, `Classical.choice`, `native_decide`, or kernel incompatibility across checkers. | High | `lake build --wfail`, `VerifyAxioms.lean`, forbidden-token scan, and Ubuntu CI `lake comparator --paranoid` (6 kernels) + Palomar CI. | Fix proof strictly within `[propext, Quot.sound]`; never relax checker flags (`AI13`). |
| **Cross-Language Biophysical Kernels (TS / Rust / Python)** | Silent floating-point formula divergence or constant typo across languages. | High | `python/tests/test_differential.py` (`2,000` cross-checks at `rtol = 1e-10`) + `scripts/mutation_audit.py` (`6/6` mutants). | Fix diverging kernel, add regression test (`B07`), re-run differential suite. |
| **Experimental Trace Parser (`apps/web` & `synapse-core`)** | Malformed JSON, NaN/Inf values, or multi-megabyte DoS payload pasted by user. | Medium | Vitest negative boundary suite (`B06`, `synapse.test.ts` lines 66–97). | Hard `2 MB` input cap and explicit `TraceParseError` / `BiophysicsValidationError`; zero uncaught exceptions. |
| **WebGL / Three.js 3D Scene (`apps/web`)** | Headless browser, GPU driver crash, or user `prefers-reduced-motion` preference. | Low | Graceful WebGL fallback & CSS/JS motion guard (`docs/accessibility.md`). | Analytical 2D tabs, charts, blueprint PNG, and proof tables remain 100% functional without WebGL. |
| **Optional Local FastAPI Server (`server.py`)** | Local server not running when visiting static GitHub Pages URL. | Low | Client health probe (`GET /healthz`) with timeout. | Automatic transparent fallback to in-browser `packages/synapse-core` TypeScript engine. |
| **Windows / Cross-OS Tooling (`scripts/`)** | Bracketed Dev-Drive paths (`[Vibe Coded (AI)]`) breaking PowerShell wildcards or Python `glob.glob()`; CRLF newlines breaking SHA-256 hashes. | Medium | 3-OS GitHub Actions matrix + `sha256sum -c MANIFEST.sha256` + `Audit-Repo.ps1` / `audit-repo.sh` / `pipeline-audit.py`. | `-LiteralPath` in PowerShell, `glob.escape(root)` in `pipeline-audit.py` (`F14`), explicit `newline="\n"` on all CSV/JSON/manifest writers (`F05`). |
| **Cryptographic Manifest (`MANIFEST.sha256`)** | Editing Lean files or white papers after sealing causes `sha256sum -c` mismatch (`F12`). | Medium | Mandatory pre-commit `sha256sum -c MANIFEST.sha256` verification step. | Regenerate `MANIFEST.sha256` and re-stamp DigiCert RFC 3161 `.tsr` as the final build step prior to commit/tag. |
| **External Registries (Zenodo, SWH, Palomar, GitHub Pages)** | Transient API timeout, webhook delay, or upstream service outage. | Low | Explicit HTTP verification checks and CI status badges. | Local `git bundle` backup (`docs/ops/backup-restore.md`), mirrored `0thernes-research-archive` repo, and retryable idempotent archival endpoints. |
| **Dependency Vulnerabilities (`npm` / `uv` / `cargo`)** | Newly disclosed CVE in transitive build or media dependency (e.g., `pillow`, `vite`). | Medium | GitHub Dependabot alerts, CI `osv-scanner`, `npm audit`. | Patch affected version in lockfile (preserving `package-lock.json` `optional: true` flags), re-run full test suite, and ship patch release. |
