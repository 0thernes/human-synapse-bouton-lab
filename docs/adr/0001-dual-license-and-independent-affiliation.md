# ADR 0001: Dual Apache-2.0 / CC-BY-4.0 Licensing and Independent Researcher Attribution

- **Status:** Accepted
- **Date:** 2026-11-23

## Context
Legacy defaults referenced "0thernes LLC" and MIT / All-Rights-Reserved licenses, whereas the November 22, 2026 Defensible Independent AI Research Playbook identified that no LLC legal entity is formed yet and recommended Apache-2.0 (matching Lean/Mathlib) for code and CC-BY-4.0 for manuscripts/media.

## Decision
Per Build Standard R8 (owner precedence), credit Alexander Stephen Donahue as **Independent Researcher** (Spokane, WA, USA; ORCID `0009-0006-8168-9648`) and adopt **Apache-2.0** for all source code and Lean proofs alongside **CC-BY-4.0** for all white papers, documentation, datasets, figures, and videos.

## Consequences
Eliminates false entity claims (`F01`), ensures compatibility with Lean/Mathlib, JOSS, Palomar Registry, and Zenodo, and establishes clean SPDX license boundaries.
