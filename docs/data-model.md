# Data Model & Canonical Entities (`data-model.md`)

Prepared per Build Pipeline Models v1.0.0 (`P3.02`). This repository is stateless and database-free (no SQL schema or user accounts); all structured scientific data is version-controlled, typed, and checksum-verified.

| Entity | Primary Key / Identifier | Canonical Source of Truth | Schema / Fields | Retention & Integrity |
|---|---|---|---|---|
| **Bouton Preset (`BoutonPreset`)** | `id` (`rat_wilhelm_2014`, `human_l1_elife_2024`, `human_l4_elife_2019`, `human_l5_ijms_2020`) | `packages/synapse-core/src/biophysics.ts` (cross-checked in `lean/NonVacuity.lean` & `python/synapse_science/oracle.py`) | `id`, `species`, `region`, `totalVesicles`, `rrpMax`, `recyclingMax`, `reserveMax`, `activeZoneAreaUm2`, `citation` | Immutable per release; conservation (`rrp + recycling + reserve == totalVesicles`) proven in Lean (`T09`) & tested in Vitest (`F03`). |
| **Biophysical API Request/Response** | OpenAPI operation path (`/api/v1/*`) | `python/synapse_science/server.py` -> exported to `api/openapi.yaml` & `api/openapi.json` | Strictly typed Pydantic v2 models (`ElectrochemistryReq`, `NanodomainReq`, `SnareReq`, `BioenergeticsReq`, `EiBalanceReq`, `MetrologyReq`) | Transient in-memory compute; zero request persistence or PII. |
| **Monte Carlo Seed Record (`per_seed_results.csv`)** | `(hypothesis, arm, seed)` | `rust/synapse-sim` -> `data/experiments/per_seed_results.csv` | `seed` (`1000..1029`, `2000..2029`), `h1_aligned_pa`, `h1_offset_pa`, `h2_nano_pr`, `h2_micro_pr`, `h3_mito_atp_frac`, `h3_glyc_atp_frac`, `h3b_mito_atp_frac`, `h3b_glyc_atp_frac`, `h4_block_a_pa`, `h4_block_b_pa` | Permanent in Git + `data/MANIFEST.sha256` (LF-normalized). |
| **Statistical Summary (`stats_summary.json`)** | `hypothesis_id` (`H1`, `H2`, `H3`, `H3b`, `H4`) | `python/synapse_science/stats_experiments.py` -> `data/experiments/stats_summary.json` | `n_per_arm`, `mean_treat`, `mean_ctrl`, `delta`, `ci95_low`, `ci95_high`, `cliffs_delta`, `cohens_d`, `p_raw`, `p_holm`, `preregistered`, `verdict` | Permanent in Git + `data/MANIFEST.sha256` + root `MANIFEST.sha256`. |
| **Open Hard Problem (`OpenHardProblem`)** | `id` (`OP01`–`OP11`) & `discipline` (11 fields) | `packages/synapse-core/src/openProblems.ts` (synced with White Paper 2 Table 1) | `id`, `discipline`, `problem`, `epistemicMode`, `verifiedProgress`, `falsificationTest`, `remainingGap` | Permanent in Git; completeness asserted by `packages/synapse-core/tests/synapse.test.ts`. |
| **Classified Finding (`ClassifiedFinding`)** | `id` (`F01`–`F10` canonical core; `F11`–`F14` v1.1.2 errata addendum) | `packages/synapse-core/src/openProblems.ts`, `ERRATA.md`, `docs/reviews/2026-11-23-redteam.md` | `id`, `findingClass` (`bug|error|issue|problem|dilemma|conflict`), `title`, `rootCause`, `resolution`, `status` | Append-only audit trail; core `F01`–`F10` asserted by Vitest. |
| **Formalization Metadata (`formalization.yaml`)** | `title` + `entry_point` (`Solution.lean`) | `lean/formalization.yaml` (official `v0.4` Palomar schema) & `lean/comparator.json` | `version`, `title`, `authors`, `license`, `relationship`, `repository`, `lean_version`, `theorems` | Validated by Palomar Registry CI (`CI-6-kernel`). |
| **Citation Audit (`citation-audit.json`)** | BibTeX key (`23` entries) | `scripts/verify_citations.py` -> `docs/citation-audit.json` | `key`, `doi`, `title`, `year`, `http_status`, `retracted`, `verified_at` | Re-runnable against live Crossref API; sealed in Git. |
| **Cryptographic Seal (`MANIFEST.sha256` & `.tsr`)** | Relative file path | Root `MANIFEST.sha256`, `MANIFEST.sha256.tsr`, `dist/SHA256SUMS` | SHA-256 hex digest + DigiCert RFC 3161 trusted timestamp token | Verified via `sha256sum -c` & `openssl ts -verify`. |
