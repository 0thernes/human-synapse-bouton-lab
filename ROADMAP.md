# Roadmap

## Now (`v1.0.0`)
- Pure Lean 4.35.0 formal verification of 18 core synaptic biophysics & bipartite-coupling theorems with multi-kernel replay (`leanchecker-paranoid`, `nanoda_bin`, `con-ron`, `con-leche`, `lake comparator`).
- Refactored full-stack multi-language suite (`@synapse/core`, `rust/synapse-sim`, `python/synapse_science`, `apps/web` GitHub Pages workbench).
- Pre-registered 30-seed Monte Carlo experiments with honest refutation reporting (`H3`), vector figures, HD simulation videos, and two AMS-LaTeX white papers.

## Next (`v1.1.0`)
- Register pinned `v1.0.0` commit on the **Palomar Registry** (`submit.palomar-registry.org`) and mint a DataCite DOI via Zenodo GitHub integration.
- Add validated interval-arithmetic bounds for single-step Hodgkin–Huxley RK4 integration in Rust and Lean.
- Add optional MCell4 / BioNetGen 3D meshed geometry export scripts for active-zone Brownian verification.

## Later (`v2.0.0`)
- Multi-bouton dendritic spine compartment coupling (up to 50-contact H01 high-strength axonal motif simulator in Rust/WASM).
- Deterministic 16K EXR/TIFF Blender Molecular Nodes pipeline consuming archived PDB (`1N7S`, `1XTG`) and EMDB (`EMD-44847`, `EMD-7769`) coordinates.
- Expanded consciousness-indicator adversarial test harness comparing GNWT, RPT, and IIT functional predictions on multi-column spiking circuits.

## Not Planned
- Unfalsifiable claims of artificial sentience or macroscopic quantum-consciousness proofs without experimental refutation tests.
- Proprietary/closed-source dependencies or cloud-locked compute requirements.
